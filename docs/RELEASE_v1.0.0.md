# 决策实验室 v1.0.0

首个公开版本。一个完全离线的战术决策仿真器，用于研究连招、弹道预测、自动躲避和不同攻速下的走 A 节奏。

**不商用，只是自娱自乐。欢迎有更多想法的人在非商用、保留来源的前提下继续二创。**

## 下载

- `Decision-Lab-Setup-1.0.0-x64.exe`：Windows x64 安装版，约 115.6 MiB。
- `Decision-Lab-Portable-1.0.0-x64.zip`：Windows x64 免安装版，约 146.0 MiB，解压后运行 `决策实验室.exe`。

两个包都包含运行环境，不需要安装 Node.js。

## 本版内容

- 目标选择、三套连招序列和动作输出日志；
- 匀速直线弹道预测与安全点搜索；
- 紧急躲避优先的决策状态机；
- 8 档攻速：`0.75 / 1.00 / 1.25 / 1.50 / 1.75 / 2.00 / 2.25 / 2.50`；
- 前摇结束才结算伤害，后摇立即移动；
- 后撤走 A 与边界侧向走位；
- 攻击节奏读数和角色攻击相位圆弧；
- Windows x64 安装版与免安装版；
- 21 项单元测试及浏览器交互检查。

## 安全边界

本项目不连接《英雄联盟》，不读取或修改游戏进程，不包含注入、内存读写、反作弊绕过、皮肤修改或真实对局自动控制功能。所有角色、技能和弹道都属于程序内置的二维仿真世界。
